# PR Reviewer Service

Сервис автоматического назначения ревьюеров на Pull Request'ы.

## Описание

Сервис реализует HTTP API для:
- управления пользователями и командами,
- автоматического назначения до двух активных ревьюеров на PR из команды автора,
- переназначения ревьюеров (только для PR со статусом `OPEN`),
- получения списка PR, назначенных пользователю,
- выполнения идемпотентной операции `merge`.

## Стек

- Язык: Python 3.11+
- Фреймворк: FastAPI + Uvicorn
- База данных: PostgreSQL
- Миграции: Alembic
- Контейнеризация: Docker, docker-compose

## Локальный запуск

1. Необходимо установить `docker` и `docker-compose`.
2. Создайте файл `.env` на основе `.env_example` и заполнить переменные окружения.
3. Выполнить:

```bash
docker-compose up --build
```

или

```bash
make up
```


Сервис будет доступен на http://localhost:8080.

Все зависимости поднимаются автоматически.

В CI `.env` создается на основе github.secrets.

## API
Сервис соответствует OpenAPI-спецификации, предоставленной в задании.
